# input_modpacks

Coloque aqui os arquivos `.mrpack` (modpacks do Modrinth) que você quer converter.

Depois, na raiz do projeto, rode:

```powershell
uv run mrpack2curseforge
```

Os modpacks convertidos aparecem em `../output_modpacks/`.
Os arquivos daqui **não são apagados nem movidos** pela conversão.
